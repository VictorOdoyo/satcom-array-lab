# Experiment catalog
Twelve pass cases exercise closed loop and ephemeris-only pointing, rain, one-bit phase shifting, phase calibration, partial and total failures, beacon gaps, outliers, handover, spatial interference and constrained nulling.

Five orbit cases audit Kepler invariants, RK4 convergence, J2 secular regression, Doppler versus a geometric range derivative and Hohmann transfer costs. Five array cases cover a masked two-dimensional footprint, fixed-phase beam squint, taper loss, spatial nulling and phase precision. Six RF cases cover Monte Carlo QPSK confidence intervals, acquired bursts, coherent carrier loss, atmospheric brightness, inverse link budgets and ACM hysteresis.

Run `uv run satlab list` for exact case identifiers. All 28 default cases appear in the [computed gallery](results.md), with arrays and full inputs. Failures are retained as outputs rather than hidden by selecting successful intervals.
